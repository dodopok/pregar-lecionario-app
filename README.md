# Pregar

Aplicativo pessoal para preparar sermões, em desenvolvimento como app nativo para macOS.

## Abrir o projeto

Abra `Pregar.xcodeproj` no Xcode. O arquivo `project.yml` é a fonte de configuração do projeto XcodeGen.

## Progresso

O protótipo inicial já tem calendário, consulta à Estêvão API v2 e editor local. Escopo implementado, limitações e próximos passos estão em [docs/progresso.md](docs/progresso.md); os requisitos e decisões de produto ficam em [docs/plano-produto.md](docs/plano-produto.md).
